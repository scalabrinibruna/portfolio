# Wireframes de média fidelidade (para reproduzir no Figma)

Frames: Desktop 1440 px (conteúdo máx. 1040 px) e Mobile 390 px. Cores: fundo #0F0B24, superfície #1A1438, roxo #8B5CF6, azul #3B82F6. Fonte: Inter ou system-ui.

1. **Cabeçalho (fixo):** nome à esquerda; links Sobre mim, Projetos, Experiências, Contato à direita. No mobile vira botão Menu com lista vertical.
2. **Sobre mim:** 2 colunas. Esquerda: seletor PT/EN, saudação, nome grande, texto, chips de tecnologias, botão "Fale comigo". Direita: avatar 260 px. Mobile: avatar em cima.
3. **Projetos:** linha vertical à esquerda com marcadores; cada card com imagem (5/12) e texto (7/12): nome, período, selo, descrição, chips, link do repositório. Estado vazio: imagem hachurada.
4. **Experiências:** mesma linha do tempo; cards só com texto (atividade, instituição • período, descrição).
5. **Contato:** 4 ícones (e-mail, WhatsApp, LinkedIn, GitHub) e formulário (nome, e-mail, mensagem, botão), com estados de erro, enviando, sucesso.
6. **Rodapé:** linha única centralizada.
